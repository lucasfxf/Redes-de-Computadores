# Conversão de Bases Numéricas

Aplicação web desenvolvida em Python com Flask para converter valores entre as bases decimal, binária, octal e hexadecimal.

## Tecnologias utilizadas

- Python 3.10 ou superior
- Flask 3.1.0
- HTML
- CSS

## Requisitos

- Python instalado no computador
- pip para instalar as dependências
- Navegador web

## Estrutura do projeto

- `app.py`: código principal da aplicação.
- `requirements.txt`: lista de dependências.
- `static/css/style.css`: estilos da interface.
- `templates/`: páginas HTML da aplicação.

## Como executar

### 1. Abra o terminal nesta pasta

Entre na pasta `conversao de bases`, onde está localizado o arquivo `app.py`.

### 2. Crie um ambiente virtual

```bash
python -m venv .venv
```

### 3. Ative o ambiente virtual

No Windows (CMD):

```cmd
.venv\Scripts\activate
```

### 4. Instale as dependências

```bash
pip install -r requirements.txt
```

### 5. Execute a aplicação

```bash
python app.py
```

### 6. Acesse no navegador

Abra o endereço:

`http://127.0.0.1:5000/`

Para encerrar a aplicação, volte ao terminal e pressione `Ctrl + C`.

## Observação

A aplicação é executada localmente. Para acessá-la, é necessário iniciar o servidor Flask seguindo as instruções acima.
